# CS2 Copenhagen Major 2024 — Player Performance Analytics

## Project Context

This is a passion-driven data analytics project inspired by competitive Counter-Strike 2 esports. As someone interested in both the game and data analysis, this project explores how in-game performance metrics can be structured into a Business Intelligence dashboard.

The goal is to simulate a real-world esports analytics system using Power BI, focusing on player impact, round contribution, and performance breakdowns.

---

## Project Files

- `.pbix` Power BI dashboard file included  
- Excel dataset used for data modeling and transformation  
- Fully developed in Power BI Desktop (Edit Mode)  

---

## Dashboard Overview

The dashboard is divided into four analytical pages:

---

### Page 1: Kill Count Leaderboard

- Kill Count Leaderboard (Top Fraggers Ranking)
- Ace Achievers (Players with Aces)

**Key Stats (Card Visuals):**
- MVP Count  
- K/D Ratio  
- Headshot Count  
- Headshot Percentage  

---

### Page 2: Clutch & Killstreak Stats

- Clutch Wins Breakdown (1v1, 1v2, 1v3, 1v4 scenarios)
- Killstreak Analysis (Single, Double, Triple, Quadra kills)

**Additional Metrics:**
- Clutch performance indicators  

---

### Page 3: Assists & Damage Metrics

- Most Assists by Player  
- Damage Breakdown (Health vs Armor)  
- Opening Engagements (First kills / deaths)  
- KAST Breakdown (Kill, Assist, Survive, Traded)  

---

### Page 4: Objective & Game Impact Metrics

- Bomb Plants by Player  
- Bomb Defusals by Player  
- Clutches Lost Breakdown  
- Final Game Score Breakdown

## Technical Notes

**Power BI Features Used:**
- Card, Bar, Stacked Column, Matrix Visuals  
- Power Query for data cleaning and transformation  
- Custom slicer-based search functionality  
- Percentage formatting (K/D, KAST, Headshot %)  

**Enhancements:**
- Background image brightness adjusted using Windows Image Editor for readability  
- Clickable watermark linking to the GitHub repository for traceability
